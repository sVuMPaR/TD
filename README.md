# Medieval TD — Tower Defense (Android)

Средневековая tower defense с магией для Android. Движок: **LibGDX** (Java). Есть desktop-версия для быстрой разработки и тестирования.

## Быстрый старт

```bash
# Desktop (тестирование на ПК)
./gradlew :desktop:run

# Android APK (нужен Android SDK)
./gradlew :android:assembleDebug
```

APK: `android/build/outputs/apk/debug/android-debug.apk`

## Игровой процесс

1. Выберите уровень в главном меню
2. Нажмите **«След. волна»**, чтобы начать атаку
3. Выберите тип башни слева и коснитесь зелёной площадки для строительства
4. Коснитесь башни для улучшения или продажи
5. Не дайте врагам дойти до конца пути

## Башни

| Башня | Стоимость | Роль |
|-------|-----------|------|
| **Лучники** | 80 | Быстрая стрельба по одной цели |
| **Артиллерия** | 150 | Урон по области (взрыв) |
| **Магия** | 120 | Магический урон + замедление |

Каждая башня улучшается до **3 уровня**.

## Враги

Гоблин → Волк → Орк → Рыцарь → Дракон (усиление по волнам)

## Уровни

1. **Застава Лесного Короля** — обучающий, 5 волн
2. **Мост через пропасть** — сложнее, 6 волн

## Структура проекта

```

desktop/   — запуск на ПК (LWJGL3)
android/   — Android-приложение
assets/    — шрифты и ресурсы
docs/      — дизайн-документ
```

## Требования

- JDK 17+
- Android SDK 34 (для сборки APK)
- Gradle 8.5 (wrapper включён)
