# Medieval TD

Средневековая tower defense со стихиями. **LibGDX**, Java 17. Desktop — для разработки, Android — целевая платформа.

Версия **1.0.0**.

## Запуск

```bash
# ПК (рабочая папка — assets/)
./gradlew :desktop:run

# Debug APK
./gradlew :android:assembleDebug
```

APK: `android/build/outputs/apk/debug/android-debug.apk`

На Windows: `.\gradlew.bat :desktop:run`

## Как играть

1. Кампания: 4 карты по очереди. Есть **Продолжить**, если вышли в меню между волнами.
2. Коснитесь зелёной клетки и выберите башню из списка.
3. **След. волна** запускает атаку. Кнопка **x1 / x2 / x4** (клавиша F) ускоряет бой.
4. Храм ставится бесплатно; первый бафф (**скорость** или **урон**) стоит золото.
5. Монеты науки копятся за карты и тратятся в **Исследованиях**.
6. **Выживание** — 100 волн, все башни открыты.

Сохранение боя не хранит врагов текущей волны. Новая карта при активном сохранении спрашивает подтверждение.

## Кампания

| # | Карта | Волн | Открывается |
|---|-------|------|-------------|
| 1 | Застава Лесного Короля | 15 | Сразу, обучение |
| 2 | Мост через пропасть | 20 | Баллиста, ледяная башня |
| 3 | Замёрзшее ущелье | 20 | Огонь / лёд / молния |
| 4 | Врата Тьмы | 25 | Финал кампании |

Универсальная **Магия** есть только на картах 1–2.

## Сложность

Лёгкая / средняя / сложная: золото, жизни, HP и число врагов. На сложной — 12 жизней и меньше золота.
